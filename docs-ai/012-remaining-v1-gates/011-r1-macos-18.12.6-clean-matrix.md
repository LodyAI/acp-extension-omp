## 背景

## 变更

没有改 `src/`、`test/`、`scripts/`，也没有改 Required cases。本次只运行检查，并写下这份记录。另外在 `COMPATIBILITY.md` 增加一行「已安装本地证据」（理由见「COMPATIBILITY.md 判断」）。

### 合成边界

真实 OMP 覆盖的是 Required cases 1–8 的主路径：用例 1 的完整 `initialize` 能力集比对，以及 new、prompt、cancel、exact load/resume、invalid/missing identity、基本 usage、restart scope 和逐事件顺序。下面这些仍只由 `syntheticCases()` / `fixture.cjs` 覆盖，不是真实 OMP 证据：用例 5 的 wrong-identity 段，用例 7 的 duplicate-message / missing-cost，用例 9（missing/exit/malformed/eof），以及夹具里的模型目录。

### COMPATIBILITY.md 判断

`COMPATIBILITY.md` 要求证据包含真实可执行文件、启动参数、profile 隔离、测试结果和非秘密的诊断元数据。本记录都已具备：二进制路径与摘要、runner 固定使用的 `--mode rpc`、隔离 profile、两个工具链的结果。这份证据不弱于已有的 18.8.4 行（Homebrew 二进制、干净导出、安装后的归档、Node 26 与 22），所以按同一角色「Installed local evidence, not a release declaration」加了一行 18.12.6。

没有把「Latest stable / Previous stable」两行改指 18.12.6 / 18.12.5，原因有两个：
- 那两行要求 schema/behavior diff review，本次没有做。
- 18.12.5 没有安装，也没有测试。

改目标版本是 012 计划层面的决定（先例见 [002-latest-omp-target.md](002-latest-omp-target.md)），不由这次运行代做。`TESTING.md` 没有加对应的 Matrix record 小节，本文件就是该行的 Required test record。
