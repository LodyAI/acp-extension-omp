# 012.002 — 当前适配目标改为 OMP 18.12.2

## 背景

`000-plan.md` 写明不要沿用 2026-10-09 的 18.8.6／18.8.5，执行时再确认当前稳定版和上一稳定版。2026-10-19 已向 GitHub `can1357/oh-my-pi` 核对非 draft、非 prerelease 的发布。

## 变更

当前适配目标换成 OMP 18.12.2。`v18.12.2` 发布于 2026-10-18。回归目标换成紧邻的上一稳定版 18.12.1，发布于 2026-10-17。

`COMPATIBILITY.md` 的 Latest stable 与 Previous stable 两行，以及 `TESTING.md` 的 Remaining gates，改记这两个版本。两版都未安装、未跑 smoke 或 contract，不能写成矩阵通过。本机 Homebrew `omp` 仍是 18.8.4，不是这个目标。按仓库规则不下载 OMP。

18.2.8 仍是 Lody #930 的最低真实合同基线，不是被换掉的当前目标。更高版本号本身不证明兼容。

R1 补矩阵时，当前稳定版用 18.12.2，上一稳定版用 18.12.1。缺这两个可核验的二进制就记阻塞，不改用 `PATH` 上的 18.8.4 充数。
